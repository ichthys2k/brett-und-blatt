# Kulissen-Masters (Drachenspiel)

Dieses Verzeichnis enthält die Master-Assets aller Spiel-Kulissen in ihrer **maximal verfügbaren Auflösung**.

## Richtlinie
Alle generierten Assets werden im Repository in maximaler Auflösung archiviert, um für spätere Abwandlungen, Retuschen, High-DPI-Renderings oder Print-Zwecke verlustfrei zur Verfügung zu stehen – unabhängig davon, in welcher optimierten Auflösung (z. B. WebP) sie in der Web-App zur Laufzeit ausgeliefert werden.
