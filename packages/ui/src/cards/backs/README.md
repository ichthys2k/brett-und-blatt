# Gemalte Kartenrücken (#314)

Hier liegen die gemalten Rücken als `bub-ruecken-<id>.webp` (500 × 700 px, WebP Qualität 80, höchstens 70 KB, punktsymmetrisch aus einem Viertel zusammengesetzt). Erlaubte ids stehen in `../paintedBacks.ts`. Ein Rücken erscheint in der Auswahl, sobald seine Datei hier liegt; `tests/kartenruecken-gemalt.test.ts` prüft Namen, Größe und Punktsymmetrie. Originale nur im privaten Grafik-Repo.

Nach neuen Bildern lokal `node_modules/.vitest-cache` löschen: Der Modulcache von Vitest merkt sich das Ergebnis von `import.meta.glob` und sieht neue Dateien sonst nicht.
